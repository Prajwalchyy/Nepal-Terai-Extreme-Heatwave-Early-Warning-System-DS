# Nepal Terai Heatwave & Extreme Temperature Dataset (2000–2025)

## 1. Official Data Provenance & Source
This dataset covers **all 21 Terai districts of Nepal** from **January 1, 2000 to December 30, 2025** (9,496 continuous daily records per district).

- **Official Source**: NASA Prediction of Worldwide Energy Resources (**NASA POWER**), NASA Langley Research Center / Earth Science Division
- **Official Website**: [https://power.larc.nasa.gov](https://power.larc.nasa.gov)
- **Interactive Data Viewer**: [https://power.larc.nasa.gov/data-access-viewer/](https://power.larc.nasa.gov/data-access-viewer/)
- **API Base Endpoint**: `https://power.larc.nasa.gov/api/temporal/daily/point`
- **Methodology**: Satellite observations combined with Goddard Earth Observing System (GEOS) MERRA-2 assimilation model.
- **License / Authenticity**: Public domain open scientific data directly from the United States Government (`nasa.gov`).

## 3. Columns & Schema Included in Each CSV

| Column | Type | Example | Description |
| :--- | :--- | :--- | :--- |
| `Date` | Date (`YYYY-MM-DD`) | `2000-01-01` | Formatted calendar date |
| `YEAR` | Integer | `2000` | Observation year (2000 to 2025) |
| `DOY` | Integer (1–366) | `1` | Day of Year (captures seasonal heat cycles) |
| `District` | Categorical | `Banke` | **Name of the Terai district** |
| `Province` | Categorical | `Lumbini` | **Name of the province** |
| `Regional_Hub` | Categorical | `Nepalgunj` | Main urban center / weather station hub |
| `Latitude` | Float | `28.05` | Geographic latitude |
| `Longitude` | Float | `81.62` | Geographic longitude |
| `T2M` | Float (°C) | `16.07` | Mean 24-hour temperature |
| `T2M_MAX` | Float (°C) | `24.02` | **Daily Maximum Temperature (Heatwave target ≥ 40°C)** |
| `T2M_MIN` | Float (°C) | `10.40` | Daily Minimum Temperature (Nighttime cooling) |
| `RH2M` | Float (%) | `21.03` | Relative Humidity at 2m |
| `WS2M` | Float (m/s) | `1.28` | Wind speed at 2m (captures dry westerly 'Loo' winds) |
| `PRECTOTCORR` | Float (mm/day) | `0.00` | Precipitation (rainfall deficit indicator) |
